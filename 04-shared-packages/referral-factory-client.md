## Behavior synopsis

HTTP client for **Referral Factory** REST API (API key auth). Used to enroll participants, fetch campaign metadata, and sync referral state for **public `/refer`** experiences and **admin referral campaigns**.

**Features controlled:** Third-party referral tracking and rewards orchestration outside Bulqit’s core DB.
